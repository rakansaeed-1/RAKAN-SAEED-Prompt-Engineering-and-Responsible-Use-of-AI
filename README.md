Training Program

This project was completed as part of the Prompt Engineering and Responsible Use of AI training program at SDAIA Academy, under the supervision of Mudar Mohammed Yahya Mohammed Ibrahim AlFadhli.

The portfolio demonstrates the practical application of prompt engineering and responsible AI use in the workplace through task delegation, custom assistant design, verification and fact-checking, measured before/after results, and safe and responsible use.

Official SDAIA Academy GitHub:  https://github.com/SDAIAAcademy

## Capstone Project: CV Tailor Assistant

A custom assistant that tailors my CV to a job posting using only my verified professional facts, and lists any requirement I don't meet instead of inventing it.

- `CV_Tailor_Report.pdf`: project board (8 sections) and the results of two measured trials
- `CV_Tailor_Presentation.pdf`: 5-minute presentation
- `skill_cv-tailor_SKILL.md`: the assistant's instructions
- `cv_checker.html`: checker for the assistant's output
- `demo_backup_screenshots/`: backup screenshots of the live demo
- `test_screenshots/`: screenshots of three runs of the assistant (good fit, medium fit, impossible job) and the checker results
